1. Qui développe MémoVie ?

MémoVie est une application Android développée à titre personnel et indépendant par un développeur particulier, sous la marque ProtéFinance.

Contact : contact@protefinance.fr

2. Principe fondamental

🔒 MémoVie ne collecte aucune donnée personnelle sur des serveurs externes.
Toutes vos données restent sur votre appareil, chiffrées avec AES-256-GCM. Aucune donnée n'est envoyée à des tiers sans votre accord explicite.

Les données suivantes sont stockées uniquement en local sur votre appareil :

  • Vos notes, mémos, promesses, dettes et rappels
  • Votre profil personnel (pseudo, prénom, nom)
  • Vos contacts de l'annuaire personnel
  • Vos préférences d'application (thème, horaires de notifications)
  • Vos listes de courses, congés, entrées scolaires et voyages
  • Vos documents et pièces jointes (GED)

2b. Données de santé

Les données de santé (mesures corporelles, rendez-vous médicaux, notes de santé) sont saisies volontairement par l'utilisateur et stockées uniquement sur votre appareil, chiffrées AES-256. Elles ne sont jamais transmises, partagées ou analysées par ProtéFinance.

MémoVie n'est pas un dispositif médical et ne remplace pas un avis médical professionnel.

3. Chiffrement et sécurité

Toutes les données sont chiffrées avec AES-256-GCM via le Keystore Android. La clé de chiffrement est dérivée de votre PIN personnel avec PBKDF2 (100 000 itérations).

L'accès à l'application est protégé par :

  • Code PIN à 4 chiffres
  • Authentification biométrique (empreinte digitale, reconnaissance faciale)

4. Intelligence artificielle (optionnelle)

Si vous choisissez d'activer les fonctions IA (ELIO avancé), votre clé API Anthropic est stockée localement sur votre appareil, chiffrée. Les requêtes IA sont envoyées directement à l'API Anthropic (anthropic.com).

Consultez la politique de confidentialité d'Anthropic pour les données traitées lors des appels API. L'activation de l'IA est entièrement optionnelle.

4b. Messagerie famille (optionnelle)

Si vous activez la messagerie famille, les messages sont synchronisés via Firebase Realtime Database (Google LLC), pour permettre l'échange entre membres du foyer. Cette fonctionnalité est entièrement optionnelle et peut être utilisée sans connexion (mode local uniquement).

Consultez la politique de confidentialité de Google pour les données traitées par Firebase.

6. Partage de données

MémoVie ne partage aucune donnée avec des tiers à des fins commerciales.
Aucune publicité. Aucun tracking. Aucune analytics.

Les seuls envois de données vers l'extérieur, toujours optionnels et à votre initiative :

  • API Anthropic : uniquement si vous activez l'IA et saisissez une clé API
  • Firebase : uniquement si vous activez la messagerie famille
  • Google Drive : uniquement si vous activez la sauvegarde cloud

7. Suppression de vos données

Vous pouvez supprimer toutes vos données à tout moment :

  • Dans l'app : Réglages → Données → Supprimer toutes les données
  • Désinstallation : supprime toutes les données locales automatiquement

8. Vos droits (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :

  • Accès : export de vos données (Réglages → Exporter)
  • Rectification : modification directe dans l'application
  • Effacement : suppression dans Réglages → Données
  • Portabilité : export chiffré au format .mvault

Pour exercer ces droits ou pour toute question : contact@protefinance.fr

9. Modifications de cette politique

Cette politique peut être mise à jour. La date de dernière modification est indiquée en haut de cette page. Les modifications importantes seront notifiées dans l'application.
